From composition modules to joint discovery

CoVarNet gave me a useful way to ask which cell populations vary together across samples. In the original workflow, modules are learned from single-cell sample composition and subsequently recovered in spatial data. My August 2026 SpaCoVarNet-GS prototype asked whether spatial neighborhoods could participate in learning the modules themselves.

The implemented extensions included a shared basis across views, separate activities, graph penalties, explicit sparsity, an optional KL loss, and fixed-basis projection for held-out regions. The most informative result was also a limit: smoother activity maps did not yield a demonstrated stable gain in held-out reconstruction in the inspected pilot.

This retrospective concerns the historical 106-state, 755-sample reference and one 6,090-cell CosMx field of view, with rank 9. It is separate from the October 2026 atlas modules. CoVarNet uses R nsNMF, whose reconstruction is X ≈ W S H, followed by correlation-network selection; it should not be described as plain vanilla NMF. Original study · NMF reference manual

02 /

A Python port is not automatically an equivalent model

Project_v2 preserves a Python implementation of frequency calculation, correlation filters, module networks, reference recovery and spatial statistics. Its practical contribution is to expose numerical steps and simplify interfaces.

One detail matters: fit_nmf_modules calls sklearn NMF without explicitly selecting beta_loss or solver, while recovery implements an H-only KL update. The discovery call therefore does not reproduce R nsNMF: the documented sklearn default is Frobenius, and this call contains no nsNMF smoothing matrix S. Matching function names does not establish model equivalence. sklearn API

Fixed-W recovery preserves a learned coordinate system. Updating W on the query would instead learn a new reference. Feature order, scaling, missingness and network specificity also require their own parity checks.

03 /

One shared basis and separate activities

The prototype first worked in a common cell-state space, rather than freely coupling raw gene counts, spatial counts and sample frequencies:

X_sc ≈ W H_sc X_st ≈ W H_st W: states × modules; H_v: modules × observations

Both views share W; each has its own H. The common feature axis must be checked upstream: the low-level solver validates feature counts but cannot detect an equally sized row permutation.

min W,H_v ≥ 0 Σ_v ω_v D(X_v || W H_v) + ½ Σ_v λ_v Tr(H_v L_v H_vᵀ) + α ||W||₁ + β Σ_v ||H_v||₁ + ½ δ ||offdiag(WᵀW)||²_F

View weights are inversely proportional to observation counts before a common normalization; the pilot additionally multiplies the CosMx weight by 0.1. This controls contribution to the objective, without removing platform bias. CosMx covered only 486 of the mapper's 4,000 genes, limiting the soft state mapping.

L1 penalties explicitly regularize W and H. A factor-dissimilarity option exists, but δ was zero in the pilot. These terms do not reproduce nsNMF's S. State-graph and cross-modal anchor terms appeared in the design document but are absent from this solver.

04 /

What the graph changes

For nonnegative affinity A, weighted-degree matrix D and L=D−A, the Laplacian penalty encourages neighboring observations to have similar activities. In the H update, neighboring activity λHA enters the numerator and λHD enters the denominator. The graph acts directly on H and affects W indirectly through alternating optimization.

Local kNN uses cKDTree and sparse graph arithmetic, avoiding a dense pairwise-distance matrix. The view arrays and factors remain dense, however, and KL updates construct WH and elementwise ratios. Sparse graphs alone do not establish atlas-scale memory efficiency.

Controls included no graph, real geometry, coordinate permutation and degree-preserving rewiring. Rewiring preserves each node's unweighted degree and the global edge-weight multiset, but not each node's weighted strength. It controls specific graph properties rather than every aspect of a spatial null.

05 /

Changing the loss means changing the updates

The optional loss="kl" branch changes both factor updates and the tracked objective:

D_KL(X || Y) = Σ [X log(X/Y) − X + Y] R = X / max(WH, ε) H ← H ⊙ [ω WᵀR + λHA] / [ω Wᵀ1 + λHD + β + ε]

The W update uses RHᵀ and the corresponding H sums. xlogy handles zero terms and epsilon protects denominators. Generalized KL is valid for nonnegative frequencies; using it does not by itself establish a validated Poisson count model for normalized compositions.

Keeping λ identical across Frobenius and KL also changes its relative strength against the reconstruction term. The historical comparison is a fixed-setting sensitivity check, rather than an equally tuned contest between losses.

Seeds are algorithmic repetitions on the same tissue. Because the real graph also enters training, this consistency does not independently establish biological validity or improved generalization. Matching the frozen W showed no stable positive increment either, and agreement with an old basis is not itself a measure of a new basis's usefulness.

The next test excluded entire coordinate-derived regions, rebuilt training graphs, and projected each held-out region with W fixed. Two partition seeds each produced eight folds. Both used Frobenius training; KL blocked holdout was not established by these results.

Positive values mean higher real-graph error. These are two partitions of one field, with overlapping training folds, not 16 independent tissue replicates.

Mean MSE was lower than for the two null graphs, but fold-level directions were inconsistent; no gain over the no-graph setting was established. Importantly, the scripts set both the sc and spatial graph penalties to zero for no_graph. That contrast changes a combination of constraints and cannot isolate a spatial-graph effect.

The inspected pilot demonstrated an implemented research prototype, without a stable held-out reconstruction benefit. Improving the quantity the model explicitly regularizes is a different result from learning a more useful module basis.

Fixed-W projection is dictionary reconstruction: the observed held-out X is used to estimate its H. It keeps that X out of W learning, but does not predict an entirely unmeasured region or provide independent-patient validation.

07 /

Source balancing changes another part of the problem

A separate October sensitivity retained nsNMF but changed how much each source contributed to its KL objective. With n_s analysis units in source s, N total units and S sources, column weights w_j=N/(S n_s) give equal total source weight.

D_KL(w_j X_j || w_j Y_j) = w_j D_KL(X_j || Y_j) X′_j = w_j X_j H_j = H′_j / w_j

The implementation rescales columns, fits, and restores H. Reconstruction contributions use the effective basis WS with one-to-one component matching. This is source-weight sensitivity, rather than spatial regularization or proof of deconfounding. Project method

08 /

What I would require before scaling up

The useful question is which scientific task a changed objective should improve. A careful next comparison would keep the sc graph fixed while varying the spatial term, calibrate regularization against loss scale, and choose rank and λ within a training design.

Regional dictionary reconstruction should remain distinct from whole-slide, patient and cohort transfer. Factor scale also deserves explicit treatment: reciprocal rescaling of W and H changes penalties, and post-fit normalization does not resolve training-time scale choices.

Multi-view structure, graph constraints and KL updates became inspectable code. Their value remains conditional on the evidence: under the historical pilot's settings, the new basis had not earned a claim of better held-out reconstruction. Retaining that result is part of developing an algorithm.
